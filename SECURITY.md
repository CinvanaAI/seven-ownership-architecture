# Security and privacy boundary

This is a documentation and case-study repository. It contains no executable
platform source, credentials, runtime databases, private agent records, or
audit-session transcripts.

The current-state audits and migration ledgers can describe architectural
weaknesses in the public Skeleton snapshot. They must not be expanded with
private paths, credential material, unpublished system data, or operational
details from a non-public deployment.

If a document accidentally exposes private material, report it privately before
opening a public issue containing the same information.
