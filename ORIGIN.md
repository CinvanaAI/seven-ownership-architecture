# Origin and evidence boundary

This architecture was developed while rebuilding Skeleton, a local AI composition platform whose legacy product had accumulated a flat shell and a powerful shared runtime center.

The normative documents express the architecture itself. The dated current-state audits and migration ledgers preserve how it was applied to a real system, including conclusions that parts were partial, wrong-shaped, reference-only, hardening-pending, or cutover-pending. Those states are kept because the portfolio should show the reasoning process, not rewrite unfinished work as a finished success story.

No source code, runtime database, credentials, audit-session prompt, personal record, or private agent content is included here. The implementation snapshot lives separately in the `skeleton` repository.
